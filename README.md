# 🧹 Очистка Docker (Docker Cleanup Guide)

Шпаргалка по удалению неиспользуемых и системных данных Docker для эффективного освобождения места на жестком диске. Она содержит команды как для комплексного сброса системы, так и для точечного удаления отдельных компонентов.

---

## 📊 1. Анализ занятого места

Перед началом очистки рекомендуется проверить текущий статус дискового пространства, занятого компонентами Docker. Для этого выполните команду:

```bash
docker system df
```

Чтобы увидеть более детальную информацию по каждому объекту (размеры конкретных контейнеров, образов и томов), добавьте флаг подробного вывода:

```bash
docker system df -v
```

---

## ⚡ 2. Полная очистка одной командой (All-in-One)

Если вам необходимо максимально быстро освободить место и удалить **абсолютно все неиспользуемые ресурсы** (остановленные контейнеры, неиспользуемые сети, образы без запущенных контейнеров, кэш сборщика и тома), используйте команду глубокой очистки:

```bash
docker system prune -a --volumes -f
```

### ⚠️ Важные флаги:
*   `-a` (`--all`) — удаляет не только «висящие» (dangling) образы, но и вообще все образы, которые не привязаны ни к одному запущенному контейнеру.
*   `--volumes` — принудительно очищает все неиспользуемые тома данных. **Внимание:** убедитесь, что у вас нет важных данных в остановленных контейнерах баз данных (например, PostgreSQL, MySQL, Redis), иначе эта информация будет безвозвратно удалена.
*   `-f` (`--force`) — отключает интерактивное подтверждение (запрос "Are you sure?"), позволяя выполнить команду мгновенно.

---

## 🧹 3. Выборочная очистка по типам данных

Если полное удаление не требуется, вы можете очистить конкретные категории объектов Docker по отдельности.

### 📦 Контейнеры (Containers)

    ```bash
    docker container prune -a -f
    ```


### 💿 Образы (Images)

    docker image prune -a -f


### 💾 Тома данных (Volumes)

    ```bash
    docker volume prune -a -f
    ```


### 🛠️ Кэш сборщика (Build Cache)

    ```bash
    docker builder prune -a -f
    ```

### 🌐 Сети (Networks)

    ```bash
    docker network prune  -f
    ```
