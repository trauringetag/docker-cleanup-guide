# Очистка Docker (Docker Cleanup Guide)

Шпаргалка по удалению неиспользуемых данных Docker для освобождения места на диске.

---

## 📊 1. Анализ занятого места
Перед очисткой проверьте, сколько места занимают компоненты Docker:
```bash
docker system df
```

---

## 🧹 2. Выборочная очистка по типам данных

### Контейнеры (Containers)
Удалить все остановленные контейнеры:
```bash
docker container prune
```

### Образы (Images)
Удалить **все** неиспользуемые образы (а не только «висящие»/dangling):
```bash
docker image prune -a
```

### Тома (Volumes)
Удалить **абсолютно все** неиспользуемые тома данных (включая анонимные и именованные):
```bash
docker volume prune --all
```

### Кэш сборщика (Build Cache)
Удалить весь кэш сборки Docker (BuildKit):
```bash
docker builder prune -a
```

---

## ⚡ 3. Полная очистка одной командой (All-in-One)

Если нужно очистить **всё сразу** (остановленные контейнеры, неиспользуемые сети, образы без контейнеров и кэш сборщика):
```bash
docker system prune -a --volumes
```
*⚠️ **Внимание:** Флаг `--volumes` удалит все неиспользуемые тома. Убедитесь, что у вас нет важных данных в остановленных базах данных (например, PostgreSQL/MySQL).*
